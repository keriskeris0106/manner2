## 🎯 주요 매커니즘 & 훈련 시스템 (구구단 어드벤처 100% 매칭)

1. **🏋️‍♂️ 높임말 훈련하기 (미니게임 3종, 25초 제한시간, 1정답당 +1 Gold)**:
   - **훈련 1: 올바른 높임 표현 스피드 레이스** (상황/말 제시 후 올바른 높임표현 2지선다)
   - **훈련 2: 공손한 예절 표현 탐정** (배려/예절 대화 2지선다)
   - **훈련 3: 특수어휘 & 겸양어 짝맞추기** (진지/댁/연세/성함/저/드리다/여쭤보다 2지선다)

2. **👹 높임말 마왕 보스전 (100 Gold 필요, 10문제 완주 타임 측정)**:
   - 필요 골드: **100 Gold** (훈련 1~3을 통해 모은 골드로 입장).
   - **특수 룰**: **틀리면 정답을 맞힐 때까지 다음 문제로 넘어가지 않음!**
   - 10문제를 완주하는 데 걸리는 최단 시간 측정 후 영웅의 전당 랭킹 등록!

3. **🏆 영웅의 전당 (Hall of Heroes)**:
   - `💰 누적 골드 랭킹`
   - `🎮 미니게임 클리어 수 랭킹`
   - `⏱️ 보스 클리어 타임 랭킹`
   - `⭐ 주간 성실 랭킹`

4. **🏫 교사 클래스 관리 페이지 (오직 교사 로그인 시에만 노출!)**:
   - **학생 접속**: 학생 이름 + 교사 6자리 학급 코드 입력 ➔ 학생 접속 시 `[🏫 클래스 관리하기]` 버튼 비노출 (학생 접근 불가).
   - **교사 접속**: 원하는 6자리 숫자 입력으로 클래스 개설 및 로그인 ➔ 교사 접속 시에만 `[🏫 클래스 관리하기]` 버튼 표출 및 학급 관리 페이지 접속 허용.
   - **교사 대시보드**: 학생 학습 이력, 골드, 훈련 클리어 수, 보스전 기록, 오답 취약 분석 차트.
