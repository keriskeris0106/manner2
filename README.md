# 🌌 [존댓말 차원 탐험대] 게이미피케이션 에듀테크 웹 서비스

> **초등학교 3학년 2학기 국어 교과 과정(올바른 높임표현과 문법)**을 2D 픽셀 레트로 게이미피케이션으로 구현한 에듀테크 서비스입니다.

- **GitHub 저장소**: [https://github.com/keriskeris0106/manner2.git](https://github.com/keriskeris0106/manner2.git)
- **Vercel 배포 주소**: `manner-nu.vercel.app`

---

## 🎯 주요 기능 및 특징

1. **6자리 학급 코드 & 3박자 검증 시스템**:
   - Google OAuth 팝업 대신 교사가 원하는 숫자 6자리 고유 학급 코드(예: `363636`)를 직접 입력하여 학급 개설.
   - 6자리 입력 시 **실시간 중복 체크** (`⚠️ 이미 사용 중인 6자리 클래스 코드입니다.` / `✅ 사용 가능한 6자리 클래스 코드입니다!`).
   - 학생 접속 시 [학년, 반, 6자리 학급 코드, 실명] 3박자 정보가 교사 개설 정보와 100% 매칭될 때만 접속 허용.
   - `localStorage` 기반 세션 유지로 자동 로비 진입.

2. **3개 월드 퀘스트 (총 30개 세부 장소) & 5턴 대화 엔진**:
   - **월드 1 (시끌벅적 우리 마을)**: 병원, 마트, 학교, 식당, 우체국, 경찰서, 소방서, 도서관, 은행, 버스정류장 (10개 장소)
   - **월드 2 (신비한 동화 월드)**: 흥부전, 토끼전, 선녀와 나무꾼, 콩쥐팥쥐, 방귀쟁이 며느리, 심청전, 금도끼 은도끼, 해와 달이 된 오누이, 혹부리 영감, 은혜 갚은 까치 (10개 장소)
   - **월드 3 (차원 대통합)**: 미래 병원에 온 용왕님, 마트에 온 자라, 학교에 온 사슴 등 10개 장소 (**월드 1, 2 배지 100% 획득 시 해금!**)
   - **2지선다 퀴즈 교육 원칙**: 선택지의 나머지 문장 구조와 단어를 100% 동일하게 맞추고, 오직 **'높임 표현' 부분만 다르게 구성**하여 학생들이 정확한 문법 포인트를 찾아내도록 유도.
   - **단 1회 오답 시 즉시 실패**: 5턴 중 단 1번이라도 오답 선택 시 `"AI 챗봇이 대화방을 나가버렸습니다. (미션 실패)"` 팝업 표출 후 로비 이동. 5턴 연속 성공 시에만 배지 획득.

3. **배지 수집함 & 상단 GNB**:
   - 수집한 배지는 텍스트 없이 고유 아이콘(🛒, 🏰, 🏥, 👑 등)으로 표출.
   - 배지 아이콘 클릭 시 **올바른 존댓말 활용 예문 모달** 표출.
   - GNB 상단 게임 타이틀 한 줄 고정 및 '게임 종료' 콤팩트 축소 버튼.

4. **반말 몬스터 던전 (어절 블록 서바이벌)**:
   - `[주어]` + `[목적어/보어]` + `[서술어.]` 어절 단위 방어 퍼즐. 서술어 블록에는 마침표(`.`) 포함.
   - 오답 시 하트 소진 및 명예의 전당 (리더보드) 점수 등록.

5. **교사 대시보드 & 마스터 모드 (0106)**:
   - 학생 오답 통계 진단 (사물높임, 특수어휘 등) 및 상세 오답 로그 조회.
   - **교사 커스텀 예시문 출제**: 교사가 등록한 예시문은 **해당 선생님의 학급 학생들에게만 최우선 출제**되도록 범위(Scope) 격리 적용.
   - **제작자 마스터 모드**: 암호 `0106` 입력 시 글로벌 대화 DB 및 시스템 프롬프트 템플릿 실시간 수정/동기화.

## 🚀 GitHub 및 Vercel 배포 방법

### 1. GitHub 업로드 (터미널 명령)

```bash
git init
git add .
git commit -m "Feat: Initial commit for 존댓말 차원 탐험대 v2.0"
git branch -M main
git remote add origin https://github.com/keriskeris0106/manner2.git
git push -u origin main --force
```

### 2. Vercel 배포 설정

1. [Vercel Dashboard](https://vercel.com) 로그인
2. **Add New Project** -> `https://github.com/keriskeris0106/manner2.git` 선택
3. **Framework Preset**: `Other` 또는 `Static HTML`
4. **Deploy** 클릭 -> 최종 `manner-nu.vercel.app` 배포 완료!
